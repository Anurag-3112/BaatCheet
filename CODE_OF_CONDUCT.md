# Code of Conduct

## Our Pledge

We are committed to making participation in BaatCheet a welcoming, respectful, and inclusive experience for everyone.

We welcome contributions from people of all experience levels and backgrounds.

As contributors and maintainers, we pledge to:

- Be respectful and professional.
- Be welcoming to newcomers.
- Give constructive feedback.
- Accept different opinions and approaches.
- Focus on what is best for the project and community.
- Treat everyone with kindness and respect.

---

## Expected Behavior

Examples of positive behavior include:

- Using welcoming and inclusive language.
- Respecting different viewpoints and experiences.
- Providing constructive criticism.
- Accepting feedback gracefully.
- Helping new contributors understand the project.
- Focusing on solving problems rather than blaming people.

---

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private information without permission.
- Threats or intimidation.
- Sexualized comments or unwanted advances.
- Hate speech.
- Deliberately submitting malicious code or changes.
- Any other behavior that would reasonably make another contributor feel unsafe or unwelcome.

---

## Contribution Guidelines

Contributors are expected to follow the project's contribution guidelines described in [`CONTRIBUTING.md`](CONTRIBUTING.md).

When participating in Issues, Pull Requests, Discussions, or other project spaces:

- Keep discussions relevant to the project.
- Explain technical disagreements respectfully.
- Avoid hostile or insulting language.
- Assume good intentions.
- Be open to learning from others.

---

## Maintainer Responsibilities

Project maintainers are responsible for:

- Maintaining a welcoming community.
- Reviewing contributions fairly.
- Addressing inappropriate behavior.
- Taking reasonable action when this Code of Conduct is violated.
- Helping contributors understand project expectations.

---

## Reporting Issues

If you experience or witness unacceptable behavior, please report it to the project maintainers.

For security vulnerabilities, **do not create a public GitHub issue**. Follow the instructions in [`SECURITY.md`](SECURITY.md) instead.

For general community or conduct concerns, open a private communication with the project maintainer where possible.

---

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

1. A private or public warning.
2. Removal of inappropriate comments or contributions.
3. Temporary restriction from participating in the project.
4. Permanent removal from the project.

The response will depend on the severity and circumstances of the violation.

---

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- GitHub Discussions
- Code reviews
- Project-related communication
- Other community spaces officially associated with BaatCheet

---

## Questions

If you have questions about this Code of Conduct, please contact the project maintainer.

---

## Acknowledgment

By participating in BaatCheet, you agree to follow this Code of Conduct and help maintain a respectful and welcoming open-source community.
